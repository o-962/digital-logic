4 · Complements

Complements let a computer subtract by adding. Every base r has two of them: the diminished radix (r−1)'s complement and the radix r's complement.

1's complement (binary)

Every 0 becomes 1 and every 1 becomes 0. A number plus its 1's complement is always all ones: 10110000 + 01001111 = 11111111.

2's complement: two methods

Method 1: 1's comp + 1 Number 1 0 1 1 0 0 0 0 1's 0 1 0 0 1 1 1 1 + 1 2's 0 1 0 1 0 0 0 0
Method 2 (fast): scan from the right keep every bit up to and including the FIRST 1, flip all bits to its left 1 0 1 1 | 0 0 0 0 → flip | keep 0 1 0 1 | 0 0 0 0
Method 2 also works with a binary point: 1010.0110 → 0101.1010. Take the complement of the whole string as if the point weren't there.

Book 1.16: 16's comp of C3DF = 1000016 − C3DF = 3C21. In binary, C3DF = 1100 0011 1101 1111 and its 2's comp is 0011 1100 0010 0001 = 3C21. Same answer, because 16's complement in hex is the same thing as 2's complement in binary.

Subtracting unsigned numbers M − N with complements

r's complement method: (1) Pad both to the same number of digits n. (2) Compute M + (r's comp of N). (3) If there is an end carry, M ≥ N: discard the carry and the result is positive. (4) If there is no end carry, M < N: the result is negative. Take the r's complement of the sum and put a minus sign in front.
(r−1)'s complement method: Same steps, but use the (r−1)'s complement. If there is an end carry, add it back to the LSB (end-around carry). If not, take the (r−1)'s complement of the sum and add a minus sign.

Slides: subtraction by complement addition (4-bit)

1's complement: 5 − 1 = 5 + (−1) 0101 + 1110 (−1 in 1's comp) ───── 1 0011 carry=1 → end-around + 1 0100 = +4 5 − 6: 0101 + 1001 = 0 1110 carry=0 → result ready: 1110 = −1
2's complement: 5 − 1 0101 + 1111 (−1 in 2's comp) ───── 1 0100 carry discarded → +4 5 − 6: 0101 + 1010 = 0 1111 1111 = −1 (2's comp form)
With 2's complement you always ignore the end carry. With 1's complement you add it back. Mixing these two up is the most common mistake on this topic.
