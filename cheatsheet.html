📄 Chapter 1 Cheat Sheet

The whole chapter on one page.

1 · Positional value

(dN−1…d0.d−1…d−M)r = Σ di·ri, digits 0…r−1
  • Hex: A10 B11 C12 D13 E14 F15. After F come G16, H17, …, K20.
  • Largest n-digit number = rⁿ−1. n bits give 2ⁿ patterns.
  • K=2¹⁰ M=2²⁰ G=2³⁰ T=2⁴⁰. 32K=32768, 64M=67,108,864.
  • (10)r=r, (100)r=r², (11)r=r+1, (121)r=(r+1)².
  • Unknown base: write a polynomial in r, solve it, check every digit < r.

2 · Conversions

  • → decimal: Σ digit × weight (or Horner's method).
  • Decimal integer → r: ÷r, remainders read bottom-up.
  • Decimal fraction → r: ×r, integer parts read top-down.
  • 2↔8: 3 bits. 2↔16: 4 bits. Group outward from the point and pad zeros at the far ends.
  • 8↔16: via binary. b = aᵏ: group k digits (3↔9: 2, 4↔16: 2).
  • A fraction terminates in base 2 only if its denominator is a power of 2. 0.1₁₀ repeats.

3 · Arithmetic

  • Add: if a column sum ≥ r, subtract r and carry 1. Binary: 1+1=10, 1+1+1=11.
  • Subtract: a borrow adds r to the column. A run of zeros becomes (r−1)s.
  • Binary multiply: shift and add partial products. Divide: shift and subtract.
  • Any base: work in decimal per column, digit = v mod r, carry = v div r.

4 · Complements (n digits)

  • (r−1)'s = (rⁿ−1) − N: each digit becomes r−1−d. 1's: flip the bits. 9's: 9−d.
  • r's = rⁿ − N = (r−1)'s + 1. 2's shortcut: keep bits through the first 1 from the right, flip the rest.
  • 2's(10000000)=10000000. 2's(0)=0. 2's(00000001)=11111111.
  • M−N (unsigned): M + r's(N). Carry → discard it, positive. No carry → negative: −r's(sum).
  • (r−1)'s method: if there's a carry, add it to the LSB (end-around carry).

  • 2's comp MSB weight = −2ⁿ⁻¹: 11001011 = −128+75 = −53 = CB.
  • Sign extension: copy the MSB to the left (2's and 1's comp).
  • Overflow: pos+pos→neg or neg+neg→pos, i.e. Cin(MSB) ≠ Cout. Opposite signs never overflow.
  • Positive numbers look the same in all three systems.

6 · Codes

  • Bits for M items: ⌈log₂M⌉ (10→4, 26→5, 52→6, 64→6, 65→7).
  • BCD: 4 bits per digit. 1010–1111 are invalid. Add: if a digit sum >9 or carries, +0110.
  • Excess-3 = BCD + 0011. Self-complementing, not weighted.
  • 2421: 5=1011 … 9=1111. 84-2-1: 1=0111, 9=1111. Both are self-complementing.
  • Gray: g = b ⊕ (b≫1). One bit changes per step. Gray→bin uses a running XOR.
  • ASCII: 7 bits. '0'=30h, 'A'=41h, 'a'=61h, space=20h. Case differs only in bit 2⁵ (32).
  • Parity: total 1s (with P) even or odd. Detects odd numbers of errors, corrects nothing.

7 · Logic

  • AND: 1 only if all inputs are 1. OR: 1 if any input is 1. NOT: invert.
  • NAND = (xy)', NOR = (x+y)', XOR = 1 when the inputs differ, XNOR = 1 when they're equal.
  • Series switches = AND, parallel = OR. Voltage ranges guard against noise.

🚨 Top traps

  • Reading the remainders top-down (wrong). Reading the fraction digits bottom-up (wrong).
  • Padding a binary fraction on the left when grouping (wrong).
  • Taking the 2's complement of a positive number when asked for "2's complement representation".
  • Forgetting the end-around carry in 1's complement, or keeping the carry in 2's complement.
  • Choosing too few bits: the result must fit too (−88 needs 8 bits).
  • BCD ≠ binary. 16.3 in BCD is 0001 0110.0011.
  • Digits ≥ base make a number invalid. Check the base you found.
  • 1+1 = 1 in logic (OR), but 10 in binary arithmetic.
