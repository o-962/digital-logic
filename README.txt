Chapter 1 - Binary Systems: Study Site + Mastery Quiz
=====================================================
How to run:
  1. Extract the zip.
  2. Open a terminal inside the extracted folder (the one with index.html).
  3. Run:   python -m http.server 8000      (or: python3 -m http.server 8000)
  4. Open   http://localhost:8000   in your browser.
(Opening index.html directly by double-clicking also works.)
No internet needed: the fonts and KaTeX (LaTeX math) are inside the assets folder.

Pages: Home, 1 Number Systems, 2 Conversions (with an interactive step-by-step converter),
3 Arithmetic, 4 Complements, 5 Signed Numbers, 6 Binary Codes, 7 Binary Logic,
Cheat Sheet (printable), Solved Problems, Mastery Quiz (137 questions, scored 0-100).
Quiz progress is saved in your browser, so you can close the tab and resume later.
