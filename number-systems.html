1 · Number Systems

Digital systems work with discrete data such as letters and digits, not continuous (analog) signals. Binary uses only 0 and 1 because two states are easy to build with electronic circuits.

Base (radix) and positional notation

Position 0 is the digit just left of the point. Positions to the right of the point are negative: −1, −2, …

Example from the slides: (123.2)5 = 1·25 + 2·5 + 3·1 + 2·(1/5) = 25 + 10 + 3 + 0.4 = (38.4)10

Largest value with n digits

The largest n-digit number in base r is rn − 1 (all digits equal to r−1). With 16 bits that's 1111 1111 1111 1111 = 65,535 = (FFFF)16 (Book 1.4). n bits give 2n different patterns: 0 … 2n−1.

Finding an unknown base (slides Ex 5, Book 1.5, 1.6)

Write every number as a polynomial in r, solve the equation, then check that every digit is smaller than r.

(BEE)r = (2699)10 → 11r² + 14r + 14 = 2699 → 11r² + 14r − 2685 = 0 → r = 15 (the other root is negative). Check: E = 14 < 15 ✓

14/2 = 5 → (r+4)/2 = 5 → r = 6
54/4 = 13 → (5r+4)/4 = r+3 → 5r+4 = 4r+12 → r = 8
24 + 17 = 40 → (2r+4) + (r+7) = 4r → r = 11 (digit 7 < 11 ✓)

x² − 11x + 22 = 0 with roots 3 and 6 → (x−3)(x−6) = x² − 9x + 18. So (11)r = r+1 = 9 and (22)r = 2r+2 = 18, which both give r = 8.
Shortcut: (121)r = r² + 2r + 1 = (r+1)², (11)r = r + 1, (100)r = r², and (10)r = r in every base.
After solving, check the digits. If the equation gives r = 5 but the number contains the digit 7, there is no valid base.

Comparing numbers in different bases (2017 Exam Q2, Q7)

  • Same digit string, bigger base → bigger value (for strings with more than one digit): (123456)7 < (123456)8.
  • (1000100)2 = 68, (1000003)8 = 262,147, (1000002)10, (1000001)16 = 16,777,217. The binary one is smallest.
  • (61)9 = 55 < (71)8 = 57.
