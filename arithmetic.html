3 · Arithmetic in Base r

It's the same column arithmetic you learned in school. The only change is that you carry or borrow the base instead of 10.

Addition

If a column sum is ≥ base, subtract the base, write what's left, and carry 1.

Subtraction (borrow a base)

If the top digit is too small, borrow 1 from the next column. That adds r to the current column (in binary, a borrowed 1 is worth 2 = (10)2).
1 0 0 1 1 0 1 = 77 − 1 0 1 1 1 = 23 ───────────────── 0 1 1 0 1 1 0 = 54
Borrowing across a run of zeros: 1000 − 1 = 0111. Every 0 in the run becomes r−1 (a 1 in binary, a 7 in octal, an F in hex).

Multiplication (bit by bit)

In binary, each partial product is either 0 or a shifted copy of the multiplicand. Add up the partial products.

Book 1.12: 1011 + 101 = 10000 and 1011 × 101 = 110111 (11 × 5 = 55). In hex, 2E + 34 = 62 and 2E × 34 = 958 (46 × 52 = 2392).

Arithmetic in any base r

If the column arithmetic gets confusing, multiply in decimal and convert each column result: digit = result mod r, carry = result div r. (34)5 × (23)5 = 19 × 13 = 247 = (1442)5.
Don't just "add the digits". In base 8, 7+1 = 10, and in hex, F+1 = 10. Most exam mistakes in this section are carrying 10 instead of r.
